# 🛒 سیستم مدیریت فروشگاه

> یک نرم‌افزار دسکتاپ مبتنی بر Java Swing برای مدیریت فروشگاه که امکاناتی مانند مدیریت کالا و مشتری، ثبت و پردازش سفارش، سبد خرید، پشتیبانی از تاریخ شمسی، ذخیره‌سازی اطلاعات با JSON و گزارش‌گیری فروش را فراهم می‌کند.

---

# 📌 معرفی پروژه

سیستم **مدیریت فروشگاه** یک نرم افزار دسکتاپ مبتنی بر **جاوا سوینگ** است که با هدف مدیریت فرایند فروشگاه طراحی و پیاده سازی شده است

این پروژه چرخه کامل مدیریت فروش را پوشش می‌دهد؛ از تعریف دسته‌بندی و کالا تا ثبت سفارش، مدیریت مشتریان، گزارش‌گیری و تولید رسید.

---

# 🏗️ ساختار پروژه

ساختار پروژه با تفکیک مسئولیت‌ها طراحی شده تا هر بخش نقش مشخصی در سیستم داشته باشد.

```text
src
├── Main.java
├── config
├── controller
├── invoices
├── model
├── repository
├── service
├── util
└── view
```

### 🔹 Model

شامل موجودیت‌های اصلی سیستم

### 🔹 Repository

مدیریت ذخیره‌سازی و بارگذاری اطلاعات

### 🔹 Service

شامل منطق اصلی سیستم

### 🔹 Controller

مدیریت رویدادها و ارتباط بین لایه‌ها

### 🔹 View

رابط کاربری مبتنی بر Java Swing

### 🔹 Util

شامل ابزارهای کمکی پروژه

# ⚙️ فناوری‌ها و کتابخانه‌های استفاده‌شده

# 🧩 چالش‌های توسعه و راه‌حل‌ها

## 1️⃣ همگام نبودن داده‌ها بعد از ثبت سفارش

به علت توسعه تیمی و ساخته شدن چند نمونه از سرویس‌ها، برخی بخش‌ها از تغییرات ایجاد شده مطلع نبودند.

این موضوع باعث می‌شد:

* گزارش‌ها بروزرسانی نشوند
* لیست مشتری‌ها تا اجرای مجدد برنامه بروزرسانی نشود
* برخی داده‌ها ناسازگار نمایش داده شوند

### راه‌حل

نمونه اولیه سرویس‌ها به صورت **Static** مدیریت شد و تمام بخش‌ها به همان سرویس مشترک متصل شدند.

نتیجه:

✔ بروزرسانی لحظه‌ای داده‌ها
✔ حذف نیاز به Reload مجدد Repository
✔ یکپارچگی بین ماژول‌ها

---

## 2️⃣ اصلاح جستجو بر اساس تاریخ

در نسخه اولیه سیستم، جستجو تنها زمانی انجام می‌شد که هر دو مقدار تاریخ شروع و پایان وارد شوند.

### راه‌حل

شرط‌های فیلتر بازنویسی شدند تا:

* فقط تاریخ شروع قابل استفاده باشد
* فقط تاریخ پایان قابل استفاده باشد
* یا از بازه کامل استفاده شود
